# 粤教企业智能助手 · Dify DSL

文件：`../企业智能助手.yml`（已统一放在 `dify/` 根目录；Dify 1.17 对话流 `advanced-chat`）

教育服务原件 **不改**。知识库素材从 `公司信息\` 转出，放在 `knowledge\`。

需求里新人指南是 **两套库**，不是一个库塞所有文档：

1. 制度文件切片 → `企业信息.docx` + `公司新人指南.docx`
2. 标准问答对 → `常见问答对.xlsx` / `问答对文本版.txt`

`公司业务\`、`留学政策\` 是客服 Agent 用的，不要绑到本应用。

接入前后端（访问点、`.env`、注意点）见 [dify的接入前后端.md](./dify的接入前后端.md)。

## 导入步骤

1. Dify 工作室 → 导入 DSL → 选 `dify/企业智能助手.yml`。
2. 知识 → 新建两个库并解析完成：
   - **企业信息与新人指南**：上传 `knowledge/01-企业信息.md`、`knowledge/02-公司新人指南.md`
   - **常见问答对**：上传 `knowledge/03-常见问答对.md`
3. 打开本应用画布：
   - 节点「检索企业信息与新人指南」绑定第 1 个库
   - 节点「检索常见问答对」绑定第 2 个库
4. 分类器和全部 LLM 选本机已配模型（常用通义）。
5. 后端先开在 `:8002`。HTTP 用 `host.docker.internal:8002`。
6. 发布。

## 画布在干什么

```
开始 → 意图分类
  录入/查询/改状态/交日报/NL2SQL/批假/待办  → FastAPI
  组织架构 / 查阅日报 / 投诉工单（查询或结案） → FastAPI
  入职办公、IT、地址、事业部               → 知识库1（企业信息+新人指南）
  简称、划转、学费、报名账号、德国B1       → 知识库2（问答对）
  其他                                     → 能力说明
```

## 试一句

| 问 | 应走 |
|---|---|
| 公司简称是什么？ | 后端本地知识库（秒回）；Dify 问答对库作为画布备用 |
| 打印机在几楼？坏了找谁？ | 新人指南，3 楼 / IT 内线 8010 |
| 张三 13800138000 想咨询美国硕士 | FastAPI 录入 |
| 同意张三的请假 | FastAPI 审批 |
| 有哪些待处理投诉？ | FastAPI 学生业务综管 |
| 把张三的投诉标成已解决 | FastAPI 结案 + 假通知 |
