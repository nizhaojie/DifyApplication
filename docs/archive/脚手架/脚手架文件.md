## 这是什么

Vue 3 + Element Plus 的后台管理模板。v3 不再堆一堆演示页，只留后台长期要用的基础：

- 登录、会话恢复
- 服务端动态路由
- 四种布局：经典侧边栏、顶部导航、混合导航、双列侧边栏
- TagsView、请求封装、表单 / CRUD Hook
- 主题、国际化、移动端侧栏（&lt;768px）

粤教后面往 `apps/admin` 里加：研判、客服、企业助手、学生助手、报告。

## 技术栈

- Vue 3.5、Vite 8、TypeScript
- Element Plus 2、Vue Router 5、Pinia 4
- Vue I18n、UnoCSS、Axios、ECharts 6
- 包管理：pnpm（仓库钉 `pnpm@9.15.3`）
- Node：`^20.19.0 || ^22.13.0 || >=24`

工作区：

```text
apps/admin     后台（我们主要改这里）
apps/docs      文档站
packages/      通用组件、useCrud、useForm、请求、主题
```

## 本机拉起来

先装 [pnpm](https://pnpm.io/) 和符合版本的 Node，再：

```bash
git clone --branch master --single-branch https://github.com/kailong321200875/vue-element-plus-admin.git
cd vue-element-plus-admin
pnpm install
pnpm dev:admin
```

浏览器打开 `http://localhost:4000/`  
账号：`admin` / `admin`

本地用自带 Mock，可以先不接 FastAPI。接到粤教后端时，改 `apps/admin` 里的请求地址，关掉 Mock。

常用命令：

| 命令 | 作用 |
|---|---|
| `pnpm dev:admin` | 开发 |
| `pnpm build:admin` | 生产构建 |
| `pnpm preview:admin` | 预览构建结果 |
| `pnpm dev:docs` | 本地文档，默认 :4002 |

## 和粤教怎么对

1. 克隆后放到约定目录（例如 `yuejiao-web/前端代码/`），不要改教育服务原件。
2. 布局用「经典侧边栏」，对照 `脚手架展示图/01-侧栏控制台.html`（已选定）。
3. 菜单：工作台 + 客户研判 / 客服 Agent / 企业助手 / 学生助手 / 智能报告，有接口再换成动态路由。
4. 表以 `粤教/公用/表/db_init.sql` 为准；接口信封以后和后端对齐。
5. 密钥只进 `.env`，不进仓库、不进金库。
