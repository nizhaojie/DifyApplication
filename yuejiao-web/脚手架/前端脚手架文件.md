# 粤教前端 · 空白模版

日期：2026-09-07

这是能跑起来的空壳，不是业务页。布局按已选定的 **侧栏控制台**，技术栈按 **ElementAdmin v3**（Vue 3.5 + Vite 8 + Element Plus + Vue Router 5 + Pinia 4）。五个业务模块都在菜单里，点进去是空白页。

工程目录：`yuejiao-web/前端代码/`  
没有克隆 ElementAdmin 整仓（里面演示页太多）。这里只留粤教要用的壳。

---

## 怎么打开

本机已有 Node v24。在 PowerShell 里：

```powershell
cd C:\Users\Windows\Desktop\粤教\yuejiao-web\前端代码
npm install
npm run dev
```

浏览器会打开 `http://127.0.0.1:4173/`  
左侧点菜单，每个模块都是空页。

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发，默认 :4173 |
| `npm run build` | 生产构建 |
| `npm run preview` | 预览构建结果 |

还没接 FastAPI，没有登录、没有接口。

## 目录

```text
前端代码/
  index.html
  package.json
  vite.config.ts
  src/
    main.ts              入口
    App.vue
    style.css            朱红主色、深色侧栏
```

侧栏可以折叠。顶栏页签可以关掉（工作台不能关）。
