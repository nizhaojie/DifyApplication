# Vue → React 合流验收报告

> 分支：`feature/vue-react-convergence` ｜ 日期：2026-09-10 ｜ 验收人：yintianduo_0720（ZCode 协助执行）

本报告取代旧版《MIGRATION-ACCEPTANCE.md》（该文档基于 antd 版迁移，与后续自定义 UI kit 重构后的代码已脱节）。

## 一、合流决策记录

| 决策点 | 结论 |
|---|---|
| 终点形态 | React 全量替代，删除 `yuejiao-web/前端代码/`（本次合流完成） |
| 功能基准 | Vue 已有功能必须等价；React 超集（工作台统计卡/漏斗、命令面板、移动端侧栏、自定义 UI kit）保留 |
| 客服方案 | 粤小蜜悬浮球 UI 移植到 React 全局布局，通信改走后端 `/api/v1/cs/chat`；不移植 Dify 浏览器直连与本地 mock 意图引擎 |
| 学生权限 | 后端从登录 JWT 推导学生身份，废除可伪造的 `X-User-Id` Header 契约，修复匿名越权漏洞 |
| 演示降级 | 学生页演示数据降级改为 `VITE_ENABLE_DEMO_FALLBACK` 显式开关，默认关闭、失败显式报错 |
| 组件库 | 本期不引入 shadcn/Tailwind；react-bits 维持按需摘取（fx/BlurText 已有 CJK 适配）。合流后如需再立项评估 |

## 二、验证证据

### 1. 自动化测试

- 前端：`tsc -b` 构建零错误；vitest 11/11（报告图表布局规则，与 Vue 版逐字等价移植）。
- 后端：pytest 121 通过 + 23 失败。**23 个失败为存量问题**（与本机共享 MySQL 的数据状态相关，已用 git stash 对比验证：改动前后失败清单完全一致，本次合流零新增失败）；新增 9 个测试全部通过：
  - `tests/student/test_student_auth.py`（5 例）：无 token 401、伪造 X-User-Id 被拒、学生只见自己的数据、写入绑定推导身份、无学生档案 403
  - `tests/enterprise/test_leave_approval.py`（4 例）：驳回空原因/纯空格被拒、带原因成功落库、同意允许无备注

### 2. 真实链路验证（后端 8002 + MySQL 真实数据）

- stu01 登录 → Bearer 访问学生接口返回真实数据；仅伪造 `X-User-Id`（无 token）→ 401「请先登录」
- vite 代理链路 `/api → 127.0.0.1:8002` 转发正常（http.ts 已改相对路径，消除 CORS 硬依赖与 8000/8002 注释漂移）
- 学生页显示「已连接业务服务」（真实数据，非演示模式）

### 3. 浏览器端到端冒烟（playwright + chromium，1280×720）

- 学生：登录落地 `/student`、页签渲染且工作台常驻、悬浮球存在、真实数据徽标、悬浮球对话收到后端回复（打字机效果）、SPA 导航页签自动登记、心理对话页可用

## 四、遗留问题与后续建议

1. **后端 23 个存量 pytest 失败**：集中在 `tests/report/test_psych_weekly.py` 等，与共享数据库数据状态相关，建议后续清理种子数据假设或改为事务隔离夹具。
2. **员工代查学生数据**：本期只做学生本人视角；如需员工/班主任查看学生数据，须新增带角色校验的接口（产品确认后立项）。
3. **真实流式客服**：当前悬浮球回复为前端打字机模拟；如需真 SSE，需后端 `/cs/chat` 增加 StreamingResponse（Dify streaming 模式已具备）。
4. **sonner toast 层叠样式**在错误提示连发时有视觉堆叠，可后续微调。
5. **shadcn/ui 引入评估**：底层原语（Radix/cmdk/sonner/lucide/motion）与 shadcn 完全一致，后续引入为增量迁移；建议合流稳定后单独立项。
6. 环境备忘：WSL 侧后端运行方式 `cd yuejiao-admin && .venv/bin/python -m uvicorn app.main:app --port 8002`；chromium 运行库已系统级安装（libnspr4/libnss3）。
