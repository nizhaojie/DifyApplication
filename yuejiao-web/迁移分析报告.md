# Vue → React 等价迁移 · 分析报告与实施计划

> 生成日期:2026-09-10。分析范围:`yuejiao-web/前端代码`(Vue 源,45+ 文件 / 9,524 行)与 `yuejiao-web/react-frontend`(已有 React 尝试,26 文件 / 1,731 行)全部源码逐文件对照。
> 结论先行:**react-frontend 是一次"重新设计"而非等价迁移**(主题换色、布局范式改变、大量交互缺失),要达成"功能/行为/视觉等价"目标,须按下文计划对齐重做;其中 API 层与状态骨架约四成可保留。

---

## 0. 迁移目标(约束)

1. 所有业务功能、页面、路由、交互、表单、弹窗/抽屉/下拉/Tab/分页/搜索/筛选、loading/empty/error/disabled 状态、API 调用语义、登录态/Token 行为**与 Vue 版一致**。
2. 视觉尽量像素级一致:**不换色、不换字体、不改间距/尺寸/图标/动画/响应式**。
3. 不修复 Vue 中"不优雅"的实现(如登录后默认落地 `/enterprise` 与根重定向 `/dashboard` 不一致),**行为照搬**。
4. Vue 中不可达的死代码不迁移(行为等价),Vue 侧文件不动。

### 1.1 视觉体系(`src/style.css`,614 行,全局单文件)

- 设计变量:`--el-color-primary:#c41e1e`(中国红)及 light-3~9/dark-2 全阶;`--aside:#1d1e1f`、`--aside-hover:#2b2c2d`。无暗色模式、无 Tailwind/CSS Modules。
- 字体:`'Noto Sans SC','PingFang SC','Microsoft YaHei'`;body 背景 `#f5f7fa`。
- 布局范式:`html,body,#app {height:100%; overflow:hidden}`(应用内滚动);aside 220px(折叠 64px)、header 56px、tags 40px、main `padding:16px 20px`。
- 组织:按页面簇命名的扁平全局类(`.ent-*`、`.funnel-*`、`.bar-*`、`.md-text`、`.empty-module` 等);深度定制点 6 处(菜单 hover/active `!important`、tags、report 日期选择器假壳、cs textarea、student focused-row、CsFloatWidget)。
- EP 组件面(React 需等价覆盖):container/aside/header/main/menu/sub-menu/menu-item/icon/button/input(textarea)/badge/avatar/tag/form/form-item/card/tabs/tab-pane/upload(drag)/divider/progress/table/select/option/pagination/drawer/timeline/timeline-item/tree/collapse/collapse-item/empty/dialog/radio-group/radio-button/date-picker(week、datetimerange)/row/col/alert + `ElMessage` + `ElMessageBox.confirm|prompt`。

### 1.2 路由与守卫

- 19 条路由:`/login`(public)+ AdminLayout 下 18 条扁平 children(`/dashboard`、`/profile`、`/cs`、`/enterprise`×5、`/student`×4(其中 psych/life/program 共用 `chat.vue`,靠 `meta.assistantMode` 区分)、`/report`×5、`/settings`)。`/` redirect `/dashboard`。
- `meta` 仅 4 类:`title`(面包屑与 tags 消费)、`hint`(死属性,UI 不消费)、`public`(仅 login)、`assistantMode`(student/chat 消费)。**无角色/权限系统**。
- 守卫:`beforeEach` 只查 `localStorage['yuejiao_token']` 存在,否则 `{path:'/login', query:{redirect: to.fullPath}}`;401 由 axios 拦截器处理(清 token + `location.href='/login'`)。
- `user.hydrate()` 已定义但**从未被调用**(启动不校验 token 有效性)。

### 1.3 状态管理(Pinia → React 映射)

| Pinia store | 内容 | React 对应 |
|---|---|---|
| `stores/user.ts` | `token`/`user` 初始化自 `yuejiao_token`/`yuejiao_user`;getter `displayName`(`real_name \|\| '未登录'`)、`loggedIn`;action `login`(写双 key)、`hydrate`(未调用)、`logout`(清双 key) | zustand `authStore`(已等价,保留;补 `displayName`) |
| `stores/tags.ts` | `visited: {path,title}[]`,初始 `[/dashboard 工作台]`;`add` 按 path 去重;`remove` 保护 `/dashboard`;不持久化,由 AdminLayout `watch(route.path,{immediate:true})` 驱动 | 新建 zustand `tagsStore` + AdminLayout 副作用 |
| `stores/cs_*`(5 个,818 行)+ `CsFloatWidget.vue` | 悬浮客服 widget 全套:Dify SSE 流式客户端、mock 回复引擎(13 场景 + 槽位多轮)、会话持久化(`cs_visitor_session`) | **死代码**(全仓无 import,`/dify-api` 亦无代理)→ 不迁移,见 §4 |
| 企业助手会话态 | 组件内 ref,挂载时 `fetchMemory()` 恢复 `conversation_id` + 历史消息 | 组件 state + 挂载时同序恢复(**当前 React 版缺失**) |

localStorage 键位(须保持兼容):`yuejiao_token`、`yuejiao_user`、`cs_session_id`(cs 页会话)。

### 1.4 API 层语义(`src/api/http.ts`)

- axios 单例:`baseURL = VITE_API_BASE || 'http://127.0.0.1:8002'`,timeout 30s(enterprise `chat` 与 report `generateReport` 单独 120s)。
- 请求拦截:`Authorization: Bearer <yuejiao_token>`;响应拦截:信封 `Envelope{code,message,data,total}`,`code!==200` → `ElMessage.error(message||'请求失败')`,`code===401` → 清 token + `location.href='/login'`;网络错误 → `ElMessage.error`。**拦截器只 toast 不解包**,各模块自行取 `data.data`。
- 模块函数面:`auth`(login/fetchMe)、`enterprise`(18 个:chat/chat-status/brief/funnel/leads(+detail/follow-ups/status)/dailies/leaves(+approve)/student-progress(+update)/tickets(+handle)/company/orgs/guide-catalog/memory(+clear))、`profile`(assessByText/assessByFile〔FormData〕/fetchProfiles〔返回整个信封〕/fetchProfileDetail)、`report`(generateReport/fetchCurrentReport〔可 null〕/fetchReportHistory,kind 5 种)、`student.ts`(**死代码,未被引用**)。
- 传输分裂(照搬,不统一):cs 页 `csApi.ts` 用**原生 fetch 走 `/api` 代理、不带 token**;student 两页用页内 fetch **硬编码 `http://127.0.0.1:8002`** + 伪造 `X-User-Id:'1'` + 10s AbortController + `{code,data}` 解包 + **失败回退内置 mock 演示数据**(student/index)。

## 3. 已有 react-frontend 的保真度审计(结论)

### 3.1 P0(不修则连不通/查不对)

| # | 问题 | 位置 | 修复 |
|---|---|---|---|
| P0-1 | dev 代理指向 **8001**,Vue 后端在 **8002**(登录页文案与学生模块硬编码均为 8002) | `react-frontend/vite.config.ts` | 代理目标改 `http://127.0.0.1:8002`,dev 端口对齐 5174 |
| P0-2 | http.ts `baseURL` 兜底 `undefined`(Vue 为 `http://127.0.0.1:8002`) | `react-frontend/src/api/http.ts` | 对齐 Vue 兜底值 |
| P0-3 | 报告周期:React 把 `<input type=date>` 值直接当 `period_start`,**无周一解析/本周区间语义** → 生成/查询错周期 | `ReportPage.tsx` | 移植 `period.ts`(含单测) |

### 3.2 整块缺失(Vue 有、React 无)

- **路由**:`/student/psych|life|program` 3 条 + `meta.assistantMode`;4 个报告子页标题落到兜底「报告详情」;**tags 多页签体系**(store + UI)整体缺失。
- **页面**:`student/index.vue`(661 行)被降级为 4 张静态跳转卡(业务能力为零);`student/chat.vue` ×3 无任何对应物;报告图表三件套(`charts.ts`/`CountChart`/`NameTable`)与 4 子页章节结构(总览/关键产出/转化路径/同比 yoy/环比 wow 文本/节点临近)缺失。
- **企业助手 8 项交互**:会话记忆恢复(fetchMemory)、「新对话」(clearMemory)、SQL 折叠、行内改状态(流失原因必填)、「学生申请」「投诉」两 Tab(连 API 都没有)、驳回请假必填原因、`fetchChatStatus` 在线态、IME 守卫;另有筛选无防抖、无任何成功 toast。
- **客服页 9 项**:打字机流式、意图彩色标签、耗时/Tokens、`#REG-{id}` 成功卡、报名 remark、席位/锁定态、FAQ 7 分类折叠、CitationBadge、「猜你想问」pills、重置确认。
- **研判页 2 项**:拖拽上传、match_score 进度条;抽屉 55% vs 500px;分页 8 vs 10。
- **API 层**:enterprise 缺 `fetchChatStatus`/`OrgItem`/`fetchStudentProgress`/`updateStudentProgress`/`fetchStudentTickets`/`handleStudentTicket`;student 全部端点缺失;全局错误 toast / `ElMessageBox.confirm|prompt`(含**必填 prompt**,丢失即「流失原因/驳回原因必填」逻辑消失)无等价物。
- **指南→助手联动**:guide 跳 `/enterprise?q=`,但 EnterprisePage 不读 query → 按钮实际失效。

### 3.3 视觉不等价(违反"像素级一致")

- 整套换色:Vue 中国红 `#c41e1e` + 侧栏 `#1d1e1f` → React 海军蓝 `#123a52` + 青绿 `#3f9f91`;气泡配色、激活态样式全部不同。
- 字体:React 远程引 Google Fonts(Manrope/DM Mono)→ **内网/离线演示会阻塞**;Vue 为系统字体栈。
- 布局范式:Vue 应用内滚动(100% + overflow:hidden,220px 侧栏/56px 头)→ React 文档流滚动(246px/68px + blur 顶栏 + max-width 1540px)。
- 组件形态:漏斗梯形→横向条;el-tree 恒展开;铃铛无角标;无 el-progress 等价物。

### 3.4 React 多出的行为(等价迁移应移除,除非另有决定)

- dashboard/settings 由占位改写为真实数据页(新增 API 调用与指标卡);cs 页新增活动侧栏/课程推荐表单/历史回放(Vue 的 `getEvents/getRecommendations/getSessionMessages` 零调用);登录后访问 /login 自动弹回;`hydrate()` 挂载调用;401 多清 user;新动画/「本地环境」指示器;cs 走 axios 带 token(Vue 为无 token fetch)。

### 3.5 可直接保留的部分(约四成)

`main.tsx`、`App.tsx` 骨架(补 3 路由)、`authStore`(补 displayName)、`api/auth|profile|report|cs`、`MarkdownText`(react-markdown 比 Vue 手写 v-html 渲染器更完备,渲染语义为超集)、drawer/dialog/tabs 的 CSS 骨架(需按 EP 度量重写)。
死依赖:`@tanstack/react-table`、`react-hook-form`、`zod` 0 引用 → 移除;如移植 charts 测试则新增 `vitest`。

## 6. 风险与注意

1. **字体与图标**:Element Plus 图标(14 个)在 React 侧用 lucide 近似会破坏像素一致性 → 建议直接引 `@element-plus/icons-vue` 的 SVG path 自制图标组件。
2. **EP 度量**:菜单项高度、按钮/输入框尺寸、表格行高、抽屉/弹窗遮罩与圆角需按 EP 默认 token 精确覆盖,否则"接近但不像素"。
3. **行为照搬的"怪"**:登录落地 `/enterprise`、cs 页无 token fetch、student 伪造 `X-User-Id:'1'`、报表假壳日期控件——均为 Vue 现状,不修。
4. **测试语义**:charts 单测锁定"画什么",实现可换 React 但断言不可改;维持自绘 SVG/CSS,不引图表库。
5. **localStorage 兼容**:`yuejiao_token`/`yuejiao_user`/`cs_session_id` 键名与结构不变,两版可混登。
